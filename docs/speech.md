# 游戏语音朗读

在全局设置的「语音朗读」中填写完整的 OpenAI 兼容 TTS 接口地址、模型 ID 和声线 ID。地址包含服务端实际路径，例如 `http://localhost:8000/v1/audio/speech`；Denova 不追加路径。API 密钥独立于语言模型，可留空。服务必须接受 `model`、`voice`、`input`、`response_format: "mp3"` 并返回 MP3 音频。试听使用表单当前值，保存本身不会生成语音。

游戏控制台的「控制」页中，语音卡片位于「互动图像」之后。每个故事分别保存自动朗读、朗读内容和星号过滤选项，默认关闭自动朗读、朗读完整正文、保留星号内容。接口、模型和单一声线为用户级配置；语速与音量保存在当前浏览器。

- **完整正文**：朗读已保存正文的可见文字，排除思考、工具过程、状态面板、图片、媒体、代码和链接地址。
- **仅对话**：仅提取成对的 `“”`、`""`、`「」`、`『』`。支持跨行和嵌套，不识别说话人；单引号不视为对话。未闭合的引号不朗读，筛选结果为空时不请求语音服务。
- **跳过星号动作描写**：先去除完整的 `*单星号*` 内容，再筛选引号。`**粗体**` 保留。
- **自动朗读**：只响应当前游戏中新提交的正文。加载历史、刷新、重连重放、切换版本和手工编辑不补播历史；重新生成的新版本可以自动朗读。

每个已保存回合都有朗读入口。正文上方显示播放状态，并提供暂停、继续、停止、重播或当前段重试。长正文自动分段，成功的音频保留到当前任务被替换或失效；暂停、调整语速音量和重播不会重复合成已成功的段落。当前页面只播放一路音频；手工朗读和试听替换原队列，自动朗读依序排队。

停止会取消当前请求并清空待播队列，不关闭自动朗读开关。关闭自动朗读只影响未来提交。发送新的游戏动作、离开游戏、切换故事/分支/版本、编辑正在朗读的正文，或更改服务与文本过滤配置，会停止旧音频。刷新不会恢复播放。服务失败不影响故事保存，也不会自动推进游戏。

首版不提供角色声线映射、说话人识别、语音输入、音色克隆、音频导出或写作/普通聊天中的朗读入口。


## 游戏场景环境音

在「游戏 → 控制台 → 控制 → 舞台演出」选择当前环境音，复用资料库中已启用条目的本地 MP3 / WAV 素材。开局前的选择作为初始音轨；开局后只修改当前分支的最新回合，不改正文和状态。可单独开启「允许 Agent 切换环境音」，默认关闭；关闭不会清除已选音轨。

环境音随已提交的回合保存。Agent 可以在提交新回合时选择一条适合最终场景的音轨，省略表示沿用，明确清空表示无环境音。相同音轨在连续回合间保持播放，滚动历史不会切换声音。播放器提供播放、暂停、静音和音量；声音默认不播放，刷新、切换故事/分支/版本或离开游戏后需要手动播放。

朗读和素材试听开始时暂停环境音，结束后手动继续；同一页面只保留一路有声播放。音量保存在当前浏览器，播放位置和开关不写入故事。素材缺失或浏览器阻止播放时显示重试入口，不阻塞剧情保存。本功能不生成音频，也不保证 MP3 循环无接缝。
